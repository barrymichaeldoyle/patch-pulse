## How it works

Once installed, the bot monitors packages you care about and sends a Slack notification when a new version is published to the npm registry.

When npm includes repository metadata, the notification also includes GitHub release links.

Notifications are final when posted; Patch Pulse does not add delayed thread comments or edit them later.

If you use Discord instead, see the [Discord Bot](../discord-bot) docs.
